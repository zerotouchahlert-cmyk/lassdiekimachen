Claude schneidet dein Video.

Die Anleitung aus dem Video: In 20 Minuten baust du dir mit Claude Code eine Pipeline, die aus einem Textskript ein fertiges Hochkant-Video macht — Stimme, Untertitel, Karten, Lautstärke. Ohne CapCut.

Windows / MacEinrichtung 20–40 Minutendanach ~4 Minuten pro Videokeine Programmierkenntnisse, aber ein Terminal

VorabWas du am Ende hast — und was es kostet

Ergebnis: Ein Ordner auf deinem Rechner. Du schreibst einen Text in script.txt, tippst einen Befehl, und nach ein paar Minuten liegt ein fertiges Hochkant-Video (1080×1920) da — mit deutscher Stimme, Untertiteln, die Wort für Wort mitlaufen, und drei Kartentypen (Hook, Liste, Abspann). Das ist die Basis; alles Weitere baust du mit einem Satz an Claude dazu.

Kosten: Claude Code braucht ein Claude-Abo (Pro oder Max). Alles andere — Node, Remotion, die Stimme über Edge-TTS, ffmpeg — ist kostenlos. Für Videos, die du veröffentlichst, prüfe bitte die Remotion-Lizenz: für Einzelpersonen und kleine Teams frei, größere Firmen brauchen eine Lizenz.

Ehrlich: Beim ersten Durchlauf hakt fast immer irgendwo etwas (Pfad, Python, Schrift). Das ist normal. Kopiere die Fehlermeldung in Claude Code und sag „fix das" — das ist der eigentliche Trick an der Sache.

Schritt 0Was du brauchst

  1. Node.js (Version 18 oder neuer) — nodejs.org, einfach installieren.
  2. Python 3 (für die Stimme) — python.org. Bei der Installation „Add to PATH" anhaken.
  3. ffmpeg — unter Windows: winget install ffmpeg, unter Mac: brew install ffmpeg.
  4. Claude Code — npm install -g @anthropic-ai/claude-code, dann claude im Terminal starten und anmelden.

Baue mir in diesem leeren Ordner eine Video-Pipeline für Hochkant-Kurzvideos
(1080x1920, 30 fps), die aus einer JSON-Datei ein fertiges MP4 rendert.
Nutze Remotion (React) für das Bild und edge-tts (Python) für die Stimme.
Erzeuge alle Dateien selbst und installiere die Abhängigkeiten.

1. STRUKTUR
   - package.json mit Remotion, scripts: "render" und "preview"
   - src/Root.tsx registriert eine Composition "Main", die ihre Dauer aus
     der Timeline-JSON liest
   - src/scenes/ mit drei Kartentypen:
     HookCard   { lines: string[], accentLine?: number }   – große Textzeilen,
                  eine davon in Akzentfarbe, Zeilen blenden nacheinander ein
     ListCard   { title: string, items: string[], footer?: string } –
                  Listenpunkte erscheinen nacheinander
     EndCard    { line1: string, line2?: string, brand: string }
   - src/theme.ts: Hintergrund #0F1115, Text #F4F4F2, Akzent #3DDC97,
     Schrift Inter (fett), sichere Ränder 120 px oben/unten
   - tools/tts.py: nimmt eine Textdatei, erzeugt public/audio/vo.mp3 mit
     edge-tts (Stimme de-DE-FlorianMultilingualNeural, rate +5%) UND
     public/captions/vo.srt aus den WordBoundary-Events (Cues aus 3–4
     Wörtern, keine Cues länger als 2,5 s)
   - src/Captions.tsx: zeigt die SRT als Untertitel unten (weiß, fett,
     schwarze Kontur), synchron zur Audiospur
   - scripts/render.js: rendert "Main" nach out/video.mp4 und normalisiert
     danach mit ffmpeg loudnorm auf -16 LUFS, -1 dBTP

2. TIMELINE-FORMAT (timeline.json im Root)
   {
     "fps": 30,
     "audio": "public/audio/vo.mp3",
     "captions": "public/captions/vo.srt",
     "scenes": [
       { "type": "HookCard", "start": 0,   "end": 3.5, "props": { ... } },
       { "type": "ListCard", "start": 3.5, "end": 8,   "props": { ... } },
       { "type": "EndCard",  "start": 8,   "end": 12,  "props": { ... } }
     ]
   }
   Die Composition-Dauer ist das größte "end" aller Szenen.

3. BEISPIEL
   Lege script.txt an mit diesem Text:
   "Für mein letztes Video hab ich drei Stunden geschnitten. Jetzt schreibe
   ich nur noch den Text. Stimme, Untertitel und Karten macht Claude.
   Vier Minuten statt drei Stunden."
   Lege timeline.json mit drei passenden Szenen dazu an (HookCard mit der
   Zahl "3 STUNDEN" als Akzentzeile, ListCard mit "Stimme", "Untertitel",
   "Karten", "Lautstärke", EndCard mit "Lass die KI machen").

4. ABLAUF
   Ein Befehl "npm run video" führt aus: tools/tts.py script.txt →
   scripts/render.js. Am Ende liegt out/video.mp4.

5. QUALITÄT
   - Schrift muss geladen sein, bevor gerendert wird (kein Frame ohne Text)
   - Text darf nie über den Rand laufen: lange Zeilen automatisch umbrechen
   - Ein kleiner Test, der prüft, dass die Timeline valide ist und die
     Dauer korrekt berechnet wird

Führe am Ende "npm run video" aus und sag mir den Pfad des fertigen
Videos, die Dauer und ob Untertitel und Ton synchron sind.

Schritt 3Dein erstes eigenes Video

  1. Öffne script.txt, schreib deinen Text rein (das wird gesprochen).
  2. Öffne timeline.json, passe die Karten an — was auf welcher Karte steht, wann sie kommt.
  3. Im Terminal: npm run video. Fertig ist out/video.mp4.
  4. Willst du etwas ändern? Sag es Claude Code in normalem Deutsch: „Mach die Akzentzeile größer", „Füge eine Karte mit drei Zahlen hinzu", „Die Stimme soll etwas schneller sprechen."

Häufige FragenWenn etwas hakt

„claude: command not found" — Terminal einmal schließen und neu öffnen, damit der PATH neu geladen wird.

Kein Ton in der Datei — python tools/tts.py script.txt einzeln ausführen; wenn Python meckert: pip install edge-tts.

Untertitel hängen hinterher — das ist fast immer die Render-Rate. Sag Claude Code: „Prüfe, ob die SRT-Zeiten in Frames umgerechnet werden, nicht in Sekunden."

Mac, kein winget — ffmpeg über Homebrew: brew install ffmpeg.
